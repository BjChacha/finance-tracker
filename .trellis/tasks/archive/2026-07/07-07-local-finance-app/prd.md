# PRD：本地记账 APP

## Goal

一个全本地数据管理的记账移动 APP（React Native + Expo，中文界面），无后端、无云同步，数据只存在设备本地 SQLite 中。

## Requirements

### R1 全本地数据管理
- 所有数据存储在设备本地（expo-sqlite），不依赖任何网络服务
- 金额以整数分存储与运算，展示层格式化为元（CNY）

### R2 记账核心功能
- 收入/支出记录：金额、二级分类、账户、日期、备注
- 多账户：现金/银行卡/支付宝/微信/信用卡等类型，账户可归档；余额实时聚合不落库
- 转账：单行建模（转出账户 + 转入账户 + 可选手续费），不计入收支统计
- 分类：两级中文预置分类（约 20 支出 + 8 收入），可自定义/排序/归档
- 预算管理：月度总预算 + 分类预算，进度展示（已用/剩余/日均可用），达阈值/超支提醒（本地通知，不重复触发）
- 周期记账：daily/weekly/monthly/yearly 规则，启动时幂等 catch-up 补账，月末对齐（31 号规则在 2 月取月末），支持"仅提醒待确认"模式

### R3 丰富图表可视化
- 分类占比环形图（支出/收入切换，可下钻二级分类）
- 收支趋势折线/面积图（日/周/月/年粒度）
- 月度收支对比柱状图
- 账户资产分布图、净资产趋势线
- 消费日历热力图
- 分类排行榜
- 所有图表数值必须与明细页汇总一致；空数据有占位；暗色模式可读

### R4 数据导入导出
- JSON 全量备份：带 format/schemaVersion/appVersion 头，恢复时 zod 校验 + 版本升级链 + 覆盖二次确认 + 恢复前自动安全备份
- CSV 明细导出：中文表头，UTF-8 带 BOM
- 通过系统分享/文件选择器（expo-sharing / expo-document-picker）

### R5 数据迁移框架（仅框架，可扩展）
- ImportAdapter 接口（id/displayName/fileExtensions/configSchema/detect/parse）+ AdapterRegistry
- **不内置任何特定 app 的适配器**；新增适配器 = 1 个文件 + 1 行注册
- 导入流水线：选文件 → 格式探测（按 confidence 排序）→ 配置/列映射 → 解析 → 分类/账户映射（记忆 + 相似度建议）→ 指纹去重 → 预览 → 单事务入库 → 按批次撤销
- GenericCsvAdapter 兜底：低置信度（0.2），用户手动列映射
- 编码支持：UTF-8 与 GBK（编码探测 + 手动切换）

## Constraints

- Expo Go 可直接运行（不使用需要自定义原生代码的库）
- Windows 开发环境（无 iOS 模拟器）
- TypeScript strict 模式

## Acceptance Criteria

- [x] Expo Go 真机可运行，四个 Tab（明细/图表/预算/我的）功能完整
- [x] 三种交易类型 CRUD 正确；转账余额变化正确且不计入收支统计
- [x] 图表数值与明细汇总一致（fixture 比对）
- [x] 备份→清空→恢复后逐表数据一致；低版本备份可经升级链恢复
- [x] GBK 与 UTF-8 CSV 均可经通用列映射导入；重复导入被指纹去重；批次撤销完整回滚
- [x] 一个约 10 行的示例适配器可通过"1 文件 + 1 行注册"接入（验证后删除）
- [x] 预算超阈值提醒只触发一次；系统时间前调后启动可补齐周期账
- [x] 单元测试通过：money/date、去重指纹、周期推进、备份升级链、CSV 解析
