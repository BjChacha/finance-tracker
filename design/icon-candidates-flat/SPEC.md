# 第二轮 · 极简环候选 · 共享设计规范

> 用户新要求（必须逐条满足）：
> 1. **纯白背景**；
> 2. **不要液态玻璃/光效**：移除光晕、高光、渐变、阴影、模糊，回归最基础、最极简的呈现；
> 3. **以「资产环」为基础**扩展三个图标；**环本身要承载一个明确的概念/意义**，并以环的形式简单表达；
> 4. 三个候选都**不要中间的货币符号**（用户觉得突兀、单调）——圆环中心留白。

## 1. 产品背景

- 应用名 **花哪了**（finance-tracker）：个人资产跟踪、资金流动记录、消费历史可视化、消费习惯分析与建议。
- 品牌主色：琥珀 `#F59E0B`。暖中性：`#1C1917`（近黑）`#57534E` `#A8A29E` `#D6D3D1` `#E7E5E4` `#FFFFFF`。
- 三个候选分别对应产品三项能力：**资产配置 / 预算进度 / 消费历史**。三个环都基于同一套几何语言（粗细、半径、端点），看起来像一家人。

## 2. 硬性视觉规则（本轮的核心）

- **背景**：纯白 `#FFFFFF` 全出血（不透明、无圆角）。不放任何背景装饰、光斑、渐变、纸纹。
- **纯扁平**：只允许**实色填充/描边**（solid hex）。**禁止**：`linearGradient`、`radialGradient`、`filter`、`feGaussianBlur`、`feDropShadow`、`mask` 做柔边、任何发光/投影/高光/内阴影/3D、`opacity` 低于 0.85 的图层（不要拿透明度做淡化，用实色灰阶代替）。
- **极简**：每个图标 **≤ 2 个视觉元素**（环 + 一个必要细节，如箭头/缺口）；颜色总数 ≤ 3（白、琥珀、1 个中性色）。中心必须留白，不放货币符号、圆点、文字、插图。
- **可读性**：环的描边宽度 ≥ 80px（1024 画布），整体外径 560–640px；缩到 48px 时仍是清晰的「环」。
- **纯矢量**：独立合法 SVG，`width="1024" height="1024" viewBox="0 0 1024 1024" xmlns=...`；无 `<text>`、`<image>`、外链、字体、脚本、动画。
- 所有文件都是 1024×1024；主图与 adaptive 三件套视觉一致（前景层整体缩放到安全圆内）。

## 4. 三个概念（只做你被分配的那一个）

### 1 · 配置环 Allocation Ring
**环的意义**：把「个人资产构成」直接画成一个环——三段弧 = 三类资产（如 现金/投资/其他）的占比，缺口是分割线。它不是装饰性的圆，而是一张「份额图」。
- 白色背景；环外半径 ~308、描边宽 ~96（内半径 ~212）。
- 3 段圆弧，按 50% / 30% / 20% 顺时针排布，段间用均匀小缺口分隔（缺口 ≈ 5–6°，白底透出）。
- 颜色（实色，任选一套）：琥珀 `#F59E0B` + 近黑 `#1C1917` + 中性灰 `#A8A29E`；或 琥珀 + 深灰 `#292524` + 浅灰 `#D6D3D1`。第一段（最大）用琥珀。
- 端点：建议用**平头端点（butt）**做出「图表的精确感」；也可圆头端点，但三个候选要统一风格（你在自己的候选里自洽即可）。
- 中心留白；**不要任何中心符号**。
- 小尺寸验证：48px 下三段的深浅要能区分出「份额」而不是看起来像一根断掉的环。

### 2 · 预算环 Budget Ring
**环的意义**：一圈 = 一个月的预算。完整浅灰轨道 = 本月可花总量，琥珀弧 = 已经花掉的预算（72%）——弧长就是进度，未闭合的一段就是剩余。表达「预算/消费建议」，而圆环天然就是进度。
- 白色背景；环中心线半径 260、描边宽 96（外半径 308）。
- 轨道：完整圆 `#D6D3D1`（暖石浅灰）。
- 进度：琥珀 `#F59E0B` 弧，从 12 点顺时针 72%（约 259.2°），**圆头端点**。
- 中心留白，不放数字、货币符号、圆点。
- 小尺寸验证：48px 下「琥珀弧 + 未走完的灰轨道 + 空心」要能读出进度，而不是断环。
- 说明：最初设想的「流动环（缺口 + 三角箭头）」在 48px 下箭头接缝会读成断环，已改为预算环；概念同样对应产品的预算/消费建议能力，且几何更稳。

### 3 · 年轮环 History Rings
**环的意义**：同心环 = 年轮 = 消费历史一层层累积；每一圈代表一个阶段的消费水平，越靠外越近。表达「历史纵深/消费习惯」，不是靶心。
- 白色背景；3 圈**同心圆环**，实色琥珀系（可用 3 个实色深浅：`#F59E0B` / `#FBBF24` / `#FCD34D`，或琥珀 + 两个中性灰阶），不要渐变。
- 几何：外圈半径 ~300、描边 ~80；中圈半径 ~210、描边 ~56；内圈半径 ~135、描边 ~36（数值可微调，但**粗细递减**、圈间距 ≥ 28px，让三圈清楚分开）。
- 为了让「年轮」更耐看、避免像射击靶心：可以给最外圈开一个小缺口（例如 8–12°）表达「仍在生长/最近一期」，也可让三圈缺口错位；但不要变成螺旋。
- 中心留白。
- 小尺寸验证：48px 下要能读成「三层同心环」，不能糊成一个粗圆。

> 三个候选的共同语言：同一套白色背景、同一套琥珀主色、环的粗细级别接近；差异只在「环怎么被分割/打断/叠加」。这样用户看到的是同一产品的三个方向。

## 5. 验收标准（Lead 会按此验收）

1. 白底、无渐变/滤镜/发光/阴影（脚本会做 flat-lint，命中直接判失败）。
2. 中心无货币符号、无任何多余装饰；环本身能说出概念。
3. 48px 可辨，描边不糊。
4. `icon.svg` / `adaptive-foreground.svg` / `adaptive-monochrome.svg` 三者结构自洽、安全区正确。
5. 与产品语义、品牌琥珀色一致；三个候选之间视觉差异明确（分段环 / 箭头环 / 同心环）。
