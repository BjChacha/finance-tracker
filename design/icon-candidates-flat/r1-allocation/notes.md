# 1 · 配置环 Allocation Ring

> 第二轮「极简环」候选 1：纯白底 + 纯扁平 + 三段实色弧 = 资产配置份额。

## 概念与含义

- **一句话**：把「我的钱怎么分配」直接画成一张份额图——三段弧 = 三类资产（如 现金 / 投资 / 其他）的占比 **50% / 30% / 20%**，顺时针排布，**弧间的缺口就是类别的分割线**。
- **环不是装饰性的圆**：吃掉 6° 的三道小缺口是「份额刻度」，让圆环读起来像一张 donut 份额图，而不是一个空心圆。三段合起来仍是 360° 的资产全景，缺 0% 时它就是一个完整的圆。
- **环心完全留白**：不放货币符号、圆点、文字——份额信息全部由**弧长**承载，金额/币种交给界面文字（用户的原始要求：中间符号突兀、单调）。
- **与产品**：对应「花哪了」的资产配置能力；琥珀 50% 是主色，代表最主要的那一类资产，也是品牌记忆点。

## 几何（1024 画布，viewBox 0 0 1024 1024）

| 项 | 值 |
| --- | --- |
| 画布 | 1024 × 1024，纯白 `#FFFFFF` 全出血（不透明、无圆角） |
| 环外半径 | **308**（外径 616，四周留白 204） |
| 描边宽 | **96**（中心线半径 260，内半径 212） |
| 端点 | **平头 `butt`**，缺口为穿过圆心的径向直切 |
| 缺口 | **6° × 3**，等分跨在份额边界 `0° / 180° / 288°` 上（12 点 / 6 点 / 左上） |
| 段角 | 每段 = 份额角 − 6°：琥珀 `180°−6°=174°`、近黑 `108°−6°=102°`、中性灰 `72°−6°=66°` |
| 起始 | 12 点开始，顺时针；最大段（琥珀）第一 |

> 数学上：三个缺口分别跨在 0°、180°、288° 三条「理想份额边界」的正中，因此缺口对称、弧长严格对应 50/30/20 的份额角，缺口大小恒为 6°。

## 色值（≤ 3 色，全实色）

| 角色 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#FFFFFF` | 纯白全出血 |
| 50%（最大段） | `#F59E0B` | 品牌琥珀 |
| 30% | `#1C1917` | 近黑 |
| 20% | `#A8A29E` | 中性灰 |

无渐变、滤镜、发光、投影、模糊；没有用 `opacity` 做淡化（全部 100% 不透明）。

## 设计取舍

1. **平头端点而非圆头**：96px 宽描边若用圆头，端帽半径 48px 远大于 6° 缺口（中心线弧长仅 27px），缺口会被端帽吃掉、小尺寸直接糊成一个整圆；平头既保住缺口，又带来份额图的精确感。三个候选如需统一端点风格，建议都走平头。
2. **缺口居中跨在份额边界上**：比「段末切缺口」更稳——三个缺口等宽、边界线位置严格正确，且顶部缺口正好以 12 点为中心，左右对称。
3. **中心留白**：无 ¥、无圆点、无文字；信息只由弧长表达，避免「图标里再塞一个符号」的杂乱。
4. **纯白全出血**：alpha 全 255，四角不透明；与 adaptive 背景层完全同色，主图与 Android 三件套视觉一致。
5. **颜色靠明度拉开层级**：琥珀（亮）→ 近黑（深）→ 中灰（中），每个缺口两侧都有强对比，缩到 48px 仍能读成「三段弧」。

## adaptive 三件套

- `adaptive-foreground.svg`：透明底，只有环，几何与主图完全一致；内容 bbox 半径实测 **308.55px ≤ 330px**（660px 安全圆），四角透明。
- `adaptive-background.svg`：一个 1024 × 1024 纯白 `rect`。
- `adaptive-monochrome.svg`：透明底 + 纯白 `#FFFFFF` 三段弧剪影；**保留 6° 缺口**——Android 13 主题图标重新着色后，靠缺口仍能读出「环被分成三段」，而不是一个普通圆环。

## 渲染与自检

```bash
python scripts/icon/render_svg.py design/icon-candidates-flat/r1-allocation/icon.svg design/icon-candidates-flat/r1-allocation/preview-icon.png
python scripts/icon/render_svg.py design/icon-candidates-flat/r1-allocation/icon.svg design/icon-candidates-flat/r1-allocation/preview-128.png --size 128
python scripts/icon/render_svg.py design/icon-candidates-flat/r1-allocation/icon.svg design/icon-candidates-flat/r1-allocation/preview-48.png --size 48
```

- **flat-lint**：四个 SVG 均无 `filter` / gradient / `<text>` / `<image>` / 外链 / 字体 / 脚本 / `opacity`；`width=1024 height=1024 viewBox="0 0 1024 1024"` + `xmlns` 齐全。
- **1024 像素实测**：外缘 r=308.5、内缘 r=211.3（抗锯齿误差内）；中心线处三段可见弧 173.9° / 101.9° / 66.0°，三个缺口 5.7–5.9°（均匀）。
- **48px 像素检查**：三段颜色（琥珀 / 近黑 / 中性灰）+ 三个缺口都能读出，能被识别为「被分成三段的环」而非断环。
- 遮罩模拟：iOS 圆角 / Android 圆形 / 方圆遮罩下环完整、无裁切。

## 迭代记录

- **R1**：首版 6° 缺口 + 96 描边，渲染 1024 / 128 / 48 检查 → 三段清楚、缺口干净，需确认缺口与描边权重是否为最优。
- **R2**：在系统临时目录做了并排对比（未写入仓库）：
  - 缺口 5.0 / 5.5 / 6.0 / 6.5 / 7.0°：5° 更「紧」但 48px 下缺口被抗锯齿吃掉一半；7° 超出 SPEC 的 5–6°；**取上限 6°**，兼顾大尺寸的克制与小尺寸的可读。
  - 描边 88 / 96 / 104（外半径固定 308）：88 偏细、面感弱，104 偏钝、中心留白被压缩；**96 最平衡**，也与 SPEC 的 ~96 一致。
  - iOS 圆角 / Android 圆形 / 方圆遮罩模拟通过；无中心符号、无任何多余装饰。
  - 最终几何保持不变，仅把「每段 = 份额角 − 6°、缺口跨在 0°/180°/288°」的推导补进 SVG 注释与本文档。

## 自评

- **强项**：语义一眼即懂（是份额图不是圆环）；纯扁平、零光效，完全符合本轮要求；中心留白干净；三个缺口等宽、位置对称；48px 仍可辨；与另两个候选（流动环 / 年轮环）共用同一套「白底 + 琥珀 + 同一环粗细」的语言，成组感强。
- **弱项**：与常见的 donut / 图表类图标同构，品牌独特性主要靠琥珀色与大面积留白承担；纯白图标在纯白壁纸下外缘会「消失」（Android 有掩码时影响较小）；6° 缺口在 24px 以下会弱化；大面积留白可能被部分人觉得「空」，需要与另两个候选对比取舍。
