# 3 · 年轮环 · History Rings

> 第二轮 · 极简环候选 · 纯白 + 纯扁平
> 交付目录：`design/icon-candidates-flat/r3-history/`

## 概念

- **中文名**：年轮环
- **English**：History Rings

三圈同心环就是一段消费史的横截面：像树的年轮，消费历史一层层向外累积，每一圈代表一个阶段的消费水平/记录密度。**越靠外越近、越新**，最外圈就是「当前这一年」；越往内越是陈年旧账。环的粗细从外到内递减，读起来自然形成「近的记忆最厚、远的记忆变薄」的纵深，而不是一个均匀的靶环。

最外圈在 12 点方向留了一个 **12° 的缺口**：本年度的年轮还在长、还没有闭合——这是整个图标唯一的「动态」细节，也是它区别于射击靶心/同心圆装饰的关键。

中心完全留白：没有货币符号、没有圆点，留出呼吸感。

## 设计取舍

- **只开外圈一个缺口，不做三圈错位缺口**：错位缺口会让三圈看起来像「加载中/刷新」的旋转弧线，是最容易踩的坑；单缺口 + 粗细递减已经足够讲「仍在生长」。
- **不做螺旋、不做发散装饰、不做环形进度弧**：规范明确禁止，也避免和「加载/进度」语义混淆。
- **平头端点（butt）**：缺口两侧是径向切口，像年轮被树心劈开一刀，几何上与另外两个候选（配置环同样用平头）统一；圆头端点会在 80px 描边上把 12° 的缺口吃掉。
- **粗细递减**：外 80 → 中 50 → 内 34，让视线从外向内收，是「年轮/历史纵深」的主要载体，也避免和等宽靶环撞脸。
- **琥珀渐变梯度的方向**：曾尝试「树心深、外圈浅」（真实木材的心材/边材关系）和「琥珀 + 中性灰」，前者在白底上外圈太淡、图标立不住，后者偏冷、丢掉品牌暖意，最终选「越新越鲜明」的琥珀三阶。
- **中心留白半径 71px**：在满足外径上限与 ≥28px 圈间距的前提下尽量放大中心的呼吸感；再大就要牺牲圈间距或外圈粗细。

## 自评

**强项**

- 1024 下三圈层次清楚：外圈厚重、中圈醒目、内圈浅淡，白缝 43/38px 读起来干净，白底上暖而不刺眼。
- 概念即几何：同心 + 递增历史 + 粗细递减 + 外圈未闭合，不需要额外符号解释。
- 48px 下三层环可以分开（外/中两圈实、内圈浅但仍有环带），顶部缺口在 48px 仍可见，不会糊成一个粗圆。
- 纯扁平、无渐变/滤镜/阴影/透明度；三件套与主图几何完全一致；前景半径 316 < 330。
- 与另外两个候选共享「白底 + 琥珀 + 平头端点 + 相近环宽级别」的语言，像一家人。

**弱项 / 风险**

- 同心环天然接近「靶心」意象，主要靠外圈缺口和粗细递减来破；如果只看 48px 缩略图，仍可能被第一眼读成「靶环」。这是本概念最大的取舍。
- 内圈 `#FCD34D` 在纯白上对比度只有约 1.45:1，48px 下偏淡；好在中心留白（半径 71）把它「框」住了，读起来仍是环。若后续觉得太淡，可整体加深一档（例如内圈改用 `#FBBF24`、中圈改用 `#F59E0B` 的变体），但会削弱「历史越久越淡」的语义。
- 缺口只有 12°，在 1024 大图上属于「细节级」信号，缩小后更像一个制图上的小断口；如果用户希望「仍在生长」更直白，可把缺口放大到 16–20°（会开始像进度环，不推荐）。
