# 4 · 墨笔 ¥ 预算环 Budget Ring · Ink ¥

## 概念

预算环（一圈 = 一个月预算：琥珀弧 = 已花掉的 72%，浅灰轨道 = 剩余）+ 中心**墨色 ¥**。

中心 ¥ 的处理思路：**用环自己的语言重画符号**——与进度弧相同的圆头端点、与环厚成比例的笔画（52px ≈ 环宽 96px 的 54%）、近黑 `#1C1917`（与浅灰轨道拉开层次）。¥ 不再是"贴上去的符号"，而是这套笔画系统里的一员：它和琥珀弧的两端圆头、和环的圆，用的是同一种"线"。

墨色 = 账本里的墨水，记账的原始语义。

## 为什么不突兀/不单调（对上一轮反馈的回应）

- **不突兀**：笔画语言完全同构（圆头、比例、居中），¥ 像是从环里"长"出来的；
- **不单调**：近黑 ¥ 在白底 + 浅灰轨道 + 琥珀弧之间形成最高的对比焦点，视线自然落在"钱"上。
