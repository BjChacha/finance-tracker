# 5 · 硬币 ¥ 预算环 Budget Ring · Coin ¥

## 概念

预算环 + 中心**琥珀硬币**：直径 300 的实心琥珀圆饼，¥ 以**负形（镂空）**刻在币面上，透出底下的白色。

中心 ¥ 的处理思路：**把货币变成一件"物"**。上一轮中心符号之所以突兀，是因为一根光秃秃的 ¥ 悬在空中；套上一枚硬币后，¥ 有了自己的"载体"，圆中套圆——硬币的圆与预算环的圆同构，中心不再是洞，而是"你的那枚钱"。琥珀硬币与进度弧同色：花掉的预算，就是从这枚钱里流出去的。

## 为什么不突兀/不单调

- **不突兀**：圆形硬币呼应环形轨道，几何同族；币缘与环内缘之间留 62px 白，一圈三层的节奏（环 → 白 → 币 → 白 → ¥）；
- **不单调**：负形镂空让 ¥ 成为"刻上去的"，比描边符号更有工艺感；小尺寸下即使 ¥ 细节丢失，"环 + 硬币"的剪影依然成立。

## 几何（1024 画布）

| 项 | 值 |
| --- | --- |
| 环 | 同预算环：轨道 `#D6D3D1` + 琥珀 72% 弧，r260/w96 |
| 硬币 | 实心 `#F59E0B` 圆，r=150，圆心 (512,512) |
| 镂空 ¥ | 白色笔画刻于币面：s=2.05、笔画 36 → 墨团 159×199，宽高比 0.80，包围盒精确居中 |
| 呼吸 | ¥ 最远点半径 120（距币缘 30px）；币缘 150 距环内缘 212 留 62px |
| 单色层 | 白色圆盘 + mask 把 ¥ 真正打出 alpha 洞（重新着色后仍是"硬币刻 ¥"） |

## 色值

| 角色 | 色值 |
| --- | --- |
| 背景 | `#FFFFFF` |
| 进度弧 / 硬币 | `#F59E0B`（同色，弧与币互相呼应） |
| 轨道 | `#D6D3D1` |
| 镂空 ¥ | 透出背景白 |

纯扁平：无渐变/滤镜/阴影；mask 仅用于单色层的 alpha 镂空，不产生任何视觉效果。
