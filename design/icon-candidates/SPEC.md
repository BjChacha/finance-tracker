# 应用图标候选 · 共享设计规范 v1

> 所有候选必须同时满足本文件的硬性规范与各自的艺术方向（见文末）。
> 渲染验证：`python scripts/icon/render_svg.py <你的 icon.svg> <preview.png>`

## 1. 产品与品牌

- 应用名：**花哪了**（finance-tracker）。一句话：个人资产跟踪、资金流动记录、消费历史可视化、消费习惯分析与建议。
- 品牌主色：琥珀 `#F59E0B`；语义色：支出 `#EF4444`、收入 `#10B981`、转账 `#3B82F6`。
- 暖中性色：`#FFFBEB` `#FEF3C7` `#FDE68A` `#FBBF24` `#F59E0B` `#D97706` `#B45309` `#78350F`；石色 `#FFF8EC` `#FDEBD0` `#F5F5F4` `#E7E5E4` `#78716C` `#1C1917` `#0C0A09`。
- 现有图标是「金币 + 手绘 ¥ + 七瓣花」（见 `assets/icon.png`）。新图标无需照抄，但必须一眼读成**记账 / 理财 / 资产**类应用，并保留琥珀暖色调作为品牌锚点。深色候选可自主选择深底。

## 2. 风格要求（用户原话）

矢量化 · 符合 Android/iOS 标准 · **扁平化** · **玻璃拟态（新版 iOS 液态玻璃感）** · **简约**。

- 扁平化 ≠ 纯色块：玻璃的层次也应扁平、干净，只用「半透明渐变 + 高光 + 柔影」表达材质，不画照片级反射。
- 液态玻璃：主体像一块厚的磨砂玻璃/液态玻璃，有通透感、圆润的厚度边缘、左上高光、右下柔和rim light，背景色调透过玻璃隐约可见。
- 极简：**≤ 3 个主视觉元素**；单个元素内部细节不超过 4 层。缩到 48px 仍能认出是什么。
- 不要：拟物皮革/金属拉丝、写实硬币纹理、3D 渲染感、文字标签、复杂插画。

## 3. 交付文件契约（每个候选目录内）

| 文件 | 说明 |
| --- | --- |
| `icon.svg` | 1024×1024 主图。**全出血不透明背景，四角必须不透明**，不画圆角、不留透明边（iOS/App Store 与 Expo `icon` 用）。 |
| `adaptive-foreground.svg` | 1024×1024，透明背景，只有主视觉（无背景）。内容 bounding box 必须落在中心 **直径 660px 的圆**内。 |
| `adaptive-background.svg` | 1024×1024，全出血背景层（可含光影），不透明。 |
| `adaptive-monochrome.svg` | 1024×1024，透明背景，**纯白 #FFFFFF 剪影**（系统会重新着色），主体轮廓 + 关键负形（如 ¥ 镂空）。 |
| `notes.md` | 概念名（中英）、1 段设计理由、主色值列表、最满意/最不满意的点。 |

`icon.svg` 与 `adaptive-foreground.svg` 的视觉必须一致（前景就是主图去掉背景后的版本，可整体缩放 0.92–1.0）。三者必须能同时成立。

## 4. 技术约束（SVG，浏览器渲染）

- 纯矢量：只允许 SVG 图形、`linearGradient`/`radialGradient`、`clipPath`、`mask`、`path`、`feGaussianBlur`/`feDropShadow`。禁止：位图 `<image>`、外部字体、外部文件引用、`<text>`（文字必须转成 path，且本图标不建议出现文字）。
- 滤镜必须给足区域，避免被裁：`<filter id="..." x="-30%" y="-30%" width="160%" height="160%">`。
- `backdrop-filter` 在独立 SVG 文档里无效；「背景透过玻璃」用**低透明度背景色副本 + 模糊**来模拟。
- 根节点必须写 `width="1024" height="1024" viewBox="0 0 1024 1024" xmlns="http://www.w3.org/2000/svg"`。
- 自包含、无脚本、无动画。代码要有分组注释（background / glass object / symbol / highlights）。

## 5. 标准与安全区

- **iOS**：1024×1024、sRGB、无 alpha、无预切圆角；重要内容放在中心 80%（819px）以内，四角只放背景。iOS 26 会额外叠加系统级 Liquid Glass 效果，因此图标本身应「平视可读、玻璃质感自洽」。
- **Android adaptive**：108dp 画布中 72dp（中心 66.7%）是安全区；前景内容必须落在中心 660–683px 圆内，背景全出血。Monochrome 供 Android 13+ 主题图标。
- **小尺寸**：48px 缩小检查（Lead 的构建脚本会统一生成小尺寸样张）。

## 6. 液态玻璃配方（推荐实现，可在此基础调整）

```svg
<defs>
  <!-- 玻璃主体：左上透亮 -> 右下更透 -->
  <linearGradient id="glassBody" x1="0" y1="0" x2="0.35" y2="1">
    <stop offset="0" stop-color="#FFFFFF" stop-opacity="0.68"/>
    <stop offset="0.55" stop-color="#FFFFFF" stop-opacity="0.22"/>
    <stop offset="1" stop-color="#FFFFFF" stop-opacity="0.10"/>
  </linearGradient>
  <!-- 玻璃边缘：左上白色亮边 -> 右下弱边 -->
  <linearGradient id="glassRim" x1="0" y1="0" x2="1" y2="1">
    <stop offset="0" stop-color="#FFFFFF" stop-opacity="0.95"/>
    <stop offset="0.5" stop-color="#FFFFFF" stop-opacity="0.40"/>
    <stop offset="1" stop-color="#FFFFFF" stop-opacity="0.12"/>
  </linearGradient>
  <filter id="softBlur" x="-40%" y="-40%" width="180%" height="180%">
    <feGaussianBlur stdDeviation="18"/>
  </filter>
</defs>
```

层级顺序（从上到下画）：
1. **落影**：主体轮廓 copy，下移 18–30px，`fill="#7C2D12"` 或 `#000000`，透明度 0.12–0.22，`filter="url(#softBlur)"`。
2. **玻璃底色**：主体形状填充 `glassBody`，不要纯白不透明。
3. **折射色**：clipPath 内放大一块背景色（如琥珀径向渐变），模糊 20–40，透明度 0.15–0.30，让玻璃"含光"。
4. **内高光**：主体上缘内侧一条白色模糊椭圆/弧形，透明度 0.35–0.6。
5. **边缘**：1.5–3px 渐变描边 `glassRim`；右下可再加一条 0.25 透明度的白色弧作 rim light。
6. **镜面高光**：左上角一小块白色椭圆或斜向细长条，模糊 6–14，透明度 0.5–0.8；这是"液态"感的关键，但只放一处。
7. **符号/内容**：¥、环、折线等，用不透明白色或深琥珀（对比度 ≥ 3:1），可带 1–2px 柔影或内阴影。
8. 可选：1–2 个极小的高光点/四角星（模糊 2–6），增加"玻璃珠"质感，但不要变成散点装饰。

> 自检：把渲染图缩小到 96–128px 看一眼，玻璃层不能糊成一团白；主体轮廓必须在 0.15s 内被认出来。

## 7. 各候选艺术方向（只做你被分配的那一个）

### A · liquid-coin「液态金币」
- 底色：暖浅色全出血（米白 → 琥珀，#FFF8EC → #FDE68A → #F59E0B 方向），左上白色柔光、右下琥珀辉光。
- 主视觉（2–3 个元素）：居中的**厚玻璃金币**（直径约 620px），币面中央是**镂空/压印的 ¥**（镂空更出彩：¥ 透出背后的背景色），金币右上或右下漂浮 1 颗**玻璃液滴**，可选择在币后加一道若隐若现的玻璃花瓣弧（呼应「花」，别抢主体）。
- 延续现有「金币 + ¥」识别度，但材质换成液态玻璃；浅色、清爽、亲和。
- 禁用：拟物齿边、金属反光、七片花瓣全画出来。

### B · glass-ring「玻璃资产环」
- 底色：**深色暖调**全出血（#1C1917 → #2A211B），中偏左上有一团琥珀色环境光（#F59E0B，透明度低、大范围模糊），营造"暗夜里的一盏灯"。
- 主视觉（2–3 个元素）：居中**玻璃圆环**（外半径 ~310，环宽 ~90），环上用琥珀/收入绿/支出红三段半透明发光弧表示资产构成；环的缺口处放一颗**玻璃圆珠**表示"数据点/当前进度"；中心保持空、或只留一枚极小的玻璃¥/光点（二选一，别堆）。
- 深色高对比、精致，适合"资产/数据"气质；确保深底上玻璃边缘仍可辨（rim light 要够亮）。
- 禁用：把三段弧做成彩虹色渐变、扇区饼图填满、在中心写金额。

### C · glass-trend「玻璃趋势卡」
- 底色：暖桃色/奶油色全出血（#FFF8F0 → #FCD9A8），大范围柔光，轻盈通透。
- 主视觉（2–3 个元素）：一块**悬浮的磨砂玻璃圆角卡**（约 560×470，圆角 ~120，轻微上浮感 = 落影），卡面内是**极简折线/面积趋势**（5–7 个点，线宽 ~14，白色或深琥珀，圆头圆角）；卡片右下角叠一枚**小玻璃金币/玻璃圆珠徽章**（直径 ~150），可带 ¥ 小镂空。用"卡片 + 趋势"表达消费历史与分析。
- 轻盈、现代、信息感；卡片与背景的层次靠高光与落影拉开。
- 禁用：卡内出现真实数字/文字、坐标轴、多张卡片、饼图。

## 8. 评审标准（Lead 会按此验收）

1. 1024 缩小到 48/96px 可辨认，主体不糊。
2. 玻璃感成立：能看到高光、通透、边缘厚度，而不是白色贴纸。
3. 扁平干净：没有多余装饰、渐变不超过必要层数。
4. 三个文件（icon / adaptive-foreground / monochrome）结构自洽，安全区正确。
5. 与品牌琥珀色、记账语义一致；三个候选彼此差异明显（浅金币 / 深环 / 浅卡片）。
