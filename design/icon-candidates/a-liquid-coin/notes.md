# 候选 A · 液态金币 / Liquid Coin

## 概念

**液态金币（Liquid Coin）** — 浅暖奶油底上的一枚厚蜂蜜玻璃金币，¥ 从正面玻璃层真正镂空、透出币背的深琥珀色；右上角一颗清透玻璃珠停在币缘上。延续旧图标「金币 + ¥」的识别度，材质换成扁平液态玻璃。

## 设计理由

按 SPEC 的 A 方向，底色保持 米白 → 琥珀 的暖色渐变（左上白色柔光收进角落、右下 #F59E0B→#D97706 琥珀辉光），主体是一枚直径 600px 的蜂蜜色玻璃圆片：中段白色填充只有约 0.15，内部叠一层放大、模糊的暖琥珀折射，让币「含光」而不是糊白；左上用一小段锐利的弧形高光 + 一个极小眩光点表现镜面，右下用一条白色 rim light 和一条暗色折射线交代玻璃厚度。¥ 不用实心符号，而是用 mask 从前面玻璃层真正切穿，露出币背的深琥珀渐变；切口上沿加深、下沿补亮，并加 1px 锐利切边，于是 ¥ 读作「被挖穿的洞/内凹」而不是贴上去的琥珀贴纸。右上液滴做成直径 130px 的正圆玻璃珠（透明白 + 小高光 + 落在币面的软影 + 一点透过珠子的焦散），与币缘略有重叠。总计 2 个主元素 + 1 个镂空符号，缩到 48/96/128px 时 ¥ 和币轮廓仍能辨认。

## 实现要点

- 纯矢量：仅 `path`/`circle`/`ellipse`/`rect` + 渐变 + `filter` 模糊 + `mask`/`clipPath`；无位图、无外链、无字体、无 `<text>`、无脚本/动画；根节点 `width="1024" height="1024" viewBox="0 0 1024 1024" xmlns=…`。
- 层级按 SPEC §6：落影 → 玻璃底（蜂蜜染色 + 0.15 白玻璃）→ 折射（暖光团 + 右下暖光池 + 暗色折射线）→ 内高光 → 渐变描边（3px）→ 镜面高光（弧形 glare + 眩光点）→ ¥（mask 镂空 + 上暗墙 + 下亮唇 + 1px 锐切边）。
- ¥ 几何：V 臂/竖笔 48px、两道横笔 44px，round cap/join，字形 bbox 约 216×294（居中）。
- 玻璃珠：r=65（直径 130），落在币缘、与币重叠约 22px；带镜面高光、珠内琥珀折射、币面软影与焦散。
- 落影放在 background 层，并用反相 mask 限制在币轮廓之外——玻璃保持通透，background 单独预览也干净。
- monochrome 只有一个白色 `path`：外圈圆 + ¥ 轮廓两条子路径 + `fill-rule="evenodd"`，因此镂空是真透明而不是另一种颜色。
- 安全区：foreground 内容最大半径 321.9px < 330px；monochrome 301.2px；均落在中心 660px 圆内。

## 自评

**最满意**
- ¥ 是真正的玻璃镂空（mask 切穿前玻璃层），配合上暗下亮的切口边缘，1024px 下能看出玻璃厚度，48–128px 下深琥珀 ¥ 与浅蜂蜜币面对比也够；「金币 + ¥」一眼可读，且不再是实心贴纸。
- 极简构图：一枚币 + 一颗玻璃珠 + 镂空 ¥，主体轮廓在 48px 仍清楚；玻璃珠的落影/焦散让它像停在币面上，增加「液态」感。
- 背景分区干净：左上白光收在角落、右下琥珀辉光加深，整体浅暖不灰，品牌琥珀浓度够。

**最不满意 / 可再改**
- 玻璃语汇仍略偏「光滑树脂」：币面中段的折射过渡比较连续，缺一道硬边的高光/折射切面，扁平度还能再提高（可加一道硬边玻璃反光带或第二段 rim light）。
- 币的右下边缘明度与琥珀背景接近，128px 时轮廓主要靠白色 rim light 和落影支撑；若再把背景右下压暗一点会更稳。
- 玻璃珠在 48px 基本只剩一个高光点，信息量有限（与极简取舍一致，但可再放大一点点）。
- 背景右下辉光范围偏大，构图重心略下沉；若更图标化可再收紧半径。
