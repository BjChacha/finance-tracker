# B · glass-ring 「玻璃资产环」

**概念名 / Concept**：玻璃资产环 / **Glass Asset Ring**（liquid-glass data ring · 暗夜玻璃）

**一句话**：一枚悬浮在暖色夜光里的厚玻璃资产环 —— 三段半透明发光弧是资产构成，缺口处的玻璃圆珠是"当前进度/数据点"，中心一枚极小的磨砂 ¥。

---

## 设计理由

「花哪了」的核心是"资产跟踪 + 资金流动可视化"，本候选把「资产结构」抽象成一条环：琥珀、收入绿、支出红三段低饱和的发光弧嵌在厚玻璃环里，像资金在玻璃管道中流动；环的缺口与玻璃圆珠共同构成"进行中的一笔/当前进度"的数据点隐喻，既保留记账应用的资产语义，又不画饼图、不写金额。整体走"暗夜里的一盏灯"：深暖色底 + 左上琥珀环境光，让玻璃环的左上边缘被照亮、右下隐入暗部，靠 rim light、镜面高光与折射色拉出厚度，实现 iOS 液态玻璃观感；扁平、无 3D 渲染味，缩小到 48px 仍是一眼可辨的"环 + 珠"。

## 自评

**最满意**
- 「暗夜玻璃」氛围成立：深暖底 + 左上琥珀光池 + 环右下隐入暗部，左上 1/3 外缘有细白反光弧（~4px / 0.72）、右下 rim 明显收弱；玻璃边缘在深底上清晰可辨。
- 极简与识别度：3 个主视觉（玻璃环 / 圆珠 / 极小 ¥），无文字无数字；128px 下一眼可辨"玻璃环 + 珠子 + ¥"，48px 仍能看出环与珠的轮廓。
- 层次按 SPEC 第 6 节组织：落影 → 玻璃底色 → 折射色 → 内高光 → 渐变描边 → 镜面高光 → 内容；彩色弧压在玻璃罩下层（上叠白雾 0.04–0.10 + 暖色罩染），绿/红相对品牌语义色降饱和，避免彩虹感。
- 中心 ¥ 为哑光磨砂暖白、无霓虹光晕，让环是绝对主角；圆珠为透明玻璃球（透出底色 + 内部暖光 + 白色高光 + 暖 rim + 底部焦散），不再是金属球。

**最不满意 / 已知局限**
- 三段彩色弧在环的上半部（尤其琥珀弧叠在最亮的玻璃区域）仍偏"颜色带"，缩到 48px 时基本归一为一条暖色环 + 绿/红点，构成比例的可读性有限（有意取舍，保证小尺寸不糊）。
- 玻璃环整体轮廓略呈 "C" 形，缺口在 4:30 方向；若隐若现会让人先读成"进度环"而非"资产环"——靠中心 ¥ 补足记账语义，仍非完美。
- 深底 + 半透明玻璃的层次依赖渲染器对 mask / filter 的实现；在极低亮度屏幕或强制灰度模式下，环的右下段对比会偏弱（已把外缘 rim 最小值提到 0.08，仍以暗调氛围优先）。
- 为了与 adaptive 前景（0.94 缩放）对齐落影，`icon.svg` 的环落影烘焙在背景层、与前景区差 6% 缩放；单独看 `icon.svg` 与三件套合成图有极轻微尺度差（SPEC 允许 0.92–1.0 缩放）。

**自检数据**：icon 1024×1024 四角 alpha = 255（全不透明）；foreground alpha 最大内容半径 315px（限 330）；monochrome 仅含纯白 RGB(255,255,255)、内容最大半径 293px；adaptive 合成图与 icon.svg 平均通道差 6.4/255（主要来自前景 0.94 缩放与落影烘焙）。渲染工具为 `scripts/icon/render_svg.py`（headless Edge），共迭代 8 轮（含 Lead 反馈后的针对性修改）。
