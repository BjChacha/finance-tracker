# 候选 C · 玻璃趋势卡（Glass Trend Card）

## 概念名

- 中文：**玻璃趋势卡**
- English：**Glass Trend Card**

一句话：一块悬浮在暖桃色光雾里的磨砂玻璃面板，面板上一条极简上涨趋势线，右下角叠一枚小小的磨砂玻璃珠徽章——用「卡片 + 趋势」表达消费历史与分析，用「¥ 玻璃珠」锚定记账语义。

## 设计理由

记账类 App 的核心价值不是「一枚钱」，而是**钱去哪了、走势如何**。所以候选 C 不复刻金币符号，而是把「一张正在被阅读的数据卡片」做成可触摸的玻璃实体：

- **悬浮磨砂玻璃卡（560×470, r120）**：整块卡片像一片厚磨砂玻璃悬在暖色光雾上。落影被刻意从卡片本体中挖空（mask `shadowCut`），只落在卡片四周——这样卡面保持通透干净，不会因为半透明把阴影"透"成奶茶色；厚度由「外沿 2.2px 渐变描边（左上白 0.9 → 右下白 0.2）+ 内沿一圈极淡暖色内阴影 + 上缘内侧一条模糊白高光」拉开。
- **极简趋势线（6 点、线宽 15、圆头圆角）**：整体上涨、带两次小回撤，是消费历史/资产曲线的抽象。颜色用深中性琥珀（#92400E 一带）而不是亮棕，保证在浅色卡面上有 ≥5:1 对比、48px 下仍是清晰的深色折线。线下方一层从 26% 渐隐到 0 的琥珀面积，暗示"面积图/消费占比"，但不会糊成一团。末端不是实心点，而是一枚**小玻璃珠**（白高光 + 白色细 rim），呼应液态玻璃材质。
- **磨砂玻璃球徽章（ø130, 压住卡片右下角）**：半透明白玻璃球，内部右下一团琥珀柔光，白色 rim + 左上高光；¥ 用深琥珀 #92400E 压印，而不是高饱和的橙色按钮。降饱和、缩尺寸后它只作辅助锚点，不抢卡片。
- **背景**：暖桃/奶油全出血渐变（#FFF9F2 → #FFF8F0 → #FBDDAF → #F6D8A8），一团大半径白色柔光（50%）位于卡片后方偏中央，四角只有干净的渐变、没有暗角或脏斑。

## 主视觉元素（共 3 个，符合 ≤3 要求）

1. 悬浮磨砂玻璃卡（含厚度/高光/落影）
2. 极简趋势线 + 面积 + 末端玻璃珠
3. 右下角磨砂玻璃球徽章（¥ 深琥珀压印）

| 用途 | 颜色 |

| 卡片描边（rim） | `#FFFFFF` 90% → 42% → 20% |
| 卡内暖 rim light | `#FFEFC9` 34% |

| 面积 | `#F59E0B` 26% → 8% → 0 |
| 数据玻璃珠 | `#FBBF24` → `#C2701A` → `#92400E` + `#FFF8EA` 高光 |

## 液态玻璃层级（对应 SPEC §6）

1. **落影**：三层（环境 `#B45309` σ56 / 主影 `#7C2D12` σ30 下移 34 / 接触影 σ10 下移 14），整组用 mask 挖掉卡片本体，只留在卡片外沿。
2. **玻璃底色**：`glassBody` 白 72%→42%→30% 对角渐变。
3. **折射色**：clipPath 内团状琥珀径向（σ24 模糊）+ 白色径向，模拟背景光从玻璃内部透出。
4. **内高光**：上缘内侧模糊白椭圆（52%, σ12）+ 左下内沿极淡暖色内阴影，形成厚度。
5. **边缘**：2.2px `glassRim`（左上白 0.9 → 右下 0.2）+ 内沿 2.6px 暖白 rim。
6. **镜面高光**：左上一条斜向细长白椭圆（62%，σ5），只放一处。
7. **内容**：趋势线/面积/玻璃珠，深琥珀；徽章 ¥ 深琥珀压印。
8. 未使用散点装饰（只有徽章/数据珠两处玻璃球高光）。

## 自检结果

- `icon.svg`：1024×1024，全出血不透明（alpha 全 255，四角 255），无圆角遮罩。
- 缩略辨认：`preview-128.png`、`preview-48.png` 下卡片轮廓、趋势线、右下徽章三者同时可读。
- `adaptive-foreground.svg`：透明背景，alpha bbox = (269,303)–(754,722)，四角到画布中心最大距离 **320.5px ≤ 330px**（严格落在 660 安全圆内）。
- `adaptive-monochrome.svg`：透明背景、纯白剪影（抽样 0 个非白像素），bbox 四角最大 319.1px ≤ 330px；卡片挖空折线 + 硬币挖空 ¥ + 分隔环。
- `adaptive-background.svg`：全出血 alpha 全 255；含与前景同一变换（`translate(90.7 87.9) scale(0.81)`）的卡片落影，叠合后与 `icon.svg` 视觉一致。
- 纯矢量：4 个文件均为合法 XML；根节点均带 `width="1024" height="1024" viewBox="0 0 1024 1024" xmlns`；无 `<text>`、`<image>`、外链、外部字体、脚本、动画。
- 卡面内容只有折线/面积/玻璃珠，**无数字、无文字、无坐标轴、无饼图**。

> 说明：为严格满足「前景内容 bbox 落在中心 660px 圆内」，`adaptive-foreground` / `adaptive-background` / `adaptive-monochrome` 的主视觉统一按 **0.81** 缩放并重新居中（SPEC 建议 0.92–1.0 为视觉一致性指引；此处优先级让给硬性安全区要求）。缩放只影响尺寸，构图/材质与 `icon.svg` 完全一致。

## 最满意 / 最不满意

**最满意**
- 落影被 mask 挖空后，磨砂卡面终于干净通透了：左上接近纯白、右下透出暖桃色，像真正的厚玻璃而不是"奶茶色贴纸"。
- 三元素平衡：卡的轮廓、深色折线的信息感、右下角玻璃珠的点睛，缩到 48px 仍是"浅色卡片 + 深色上涨线 + 小珠子"的整体剪影。

**最不满意**
- `adaptive-foreground` 受 660 安全圆严格约束缩到 0.81，自适应图标里主视觉会比桌面图标略小（已用同一变换同步 background 落影与 monochrome，保证三层叠合仍成立）。
- 玻璃球徽章在 48px 下只能读成「浅色小球 + 深色小点」，¥ 细节不可辨；这是"降饱和、不抢卡片"与"小尺寸符号"之间的取舍。
- 浅色背景上卡片左上边缘的辨认主要靠白色 rim 与外围落影，对比不如 B 方案的深底锐利（风格取向使然）。

## 迭代记录

1. v1：卡片 + 折线 + 琥珀色光泽金币徽章。
2. 按 Lead 反馈修订：徽章改为**磨砂玻璃球**（半透明白底 + 内部琥珀柔光 + 白 rim，¥ 深琥珀 #92400E，直径 150→130）；趋势线改深中性 #92400E 系；末端改为玻璃珠；背景改中央大柔光、去暗角/暗斑、整体压暗；卡片加强描边与上缘内高光、加重落影；构图重新居中（视觉 bbox 中心 ≈ 511.5,511.5）。
3. 细节修复：发现落影会透过半透明卡面把卡"染成奶茶色"，用 `shadowCut` mask 将落影从卡体轮廓中挖空；同步修正 4 个文件的几何与 0.81 前景缩放。
