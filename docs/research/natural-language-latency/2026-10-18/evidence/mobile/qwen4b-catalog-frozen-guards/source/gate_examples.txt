买三支牙膏合计17元 → single
给爸爸买茶叶花了180元 → single
给朋友转了28元做份子钱 → single
五月的租金已经付了900 → single
收到了退货款72元 → single
我的支付宝转到我的储蓄卡600元 → single
昨天用现金结清修理厨房水管的费用95元 → single
手机号末四位8765的话费充了40元 → single
午餐18元，公交2元 → clarify
刚买药23元，又买袜子12元 → clarify
付了费用，金额没说 → clarify
想买120元的包但还没买 → clarify
同一张小票买苹果和梨一共26元 → single
账户是否缺失与交易是否发生是不同问题。不要因为外部收款人是朋友、消费受益人是亲友、数量大于一、日期数字、已到账退款或明确的本人互转而拒绝单笔。
