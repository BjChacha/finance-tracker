# 实施方案

## 分类

基于真机已有分类整理父子层级，保留所有分类 ID 与账目。提供可预览的整理入口；仅处理无歧义的已知同义或细分类。已有子分类的一级类不自动降级，避免产生三级树。存在分类预算的一级类不降级，保留预算语义。修改前持久化完整 JSON 安全备份，事务内更新分类；整理后失效统计、预算、交易和分类缓存。

## 图表

9 月顶部交通 43.6%，饼图交通 44.4%，来自明细分类与父类汇总混用。顶部改为使用饼图同一数据源。去掉密集交叉引导线，使用环形图及有颜色标记的完整分类图例，显示金额和占比，点击高亮。补齐未分类和转账手续费，保持总支出口径一致。

## 自动备份

复用九表 JSON 和现有恢复校验。同步事务读取一致快照；应用文档目录写临时文件、回读校验、重命名。启动/回前台/前台定期检查每日备份；单实例互斥，失败不推进成功时间。默认应用内副本，可选择 Android 手机文件夹额外保存。自动副本保留最近 30 份，仅成功写入后清理自动文件；安全备份不参与轮转。配置留在本机文件中，避免恢复旧账目覆盖目录权限和开关。备份页提供开启/暂停、选目录、立即备份、历史分享/恢复和失败状态。

## 验证

覆盖备份节流、并发、失败重试、轮转、分类规划幂等及 ID 保留、统计手续费和未分类、图表数据。类型检查后构建 Release，通过 adb 更新安装而非卸载，保存前后截图和账目总数对照。
