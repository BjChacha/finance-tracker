- 底部导航：看板、流水、我的；资产和统计为二级详情。
- 消费复盘优先，所有卡片共用月／季／年周期，当前周期截至今天。

## 实现位置

- `src/lib/analytics-range.ts`：自然周期、同进度比较、路由参数规范化；`use-today-key.ts` 处理午夜与回前台刷新。
- `src/features/transactions/filters.ts`：流水与 SQL 全量汇总使用同一筛选；分页使用日期、创建时间、ID 游标。
- `src/features/accounts/history*.ts`：逐账户原币累计，再按当前账户汇率估值；账户查询支持截止日。
- `src/features/dashboard/`：看板组合、周期控件、分类和资产详情；路由只负责装配。
- `src/features/transactions/components/ledger-screen.tsx`：一级流水与筛选流水复用内容，状态独立。
- 原 `/assets`、`/stats`、`/transactions` 保留；`/ledger` 为一级入口。

## 真机发现与修复

- 多年历史受最小点间距限制会截断后半段：现按可用宽度容纳完整序列，并保留首尾标签。
- 图表库的滑动指针会拒绝纵向滚动接管：改为点击选点和持续读数，使用原始分值显示准确金额。
- 页签测试的模拟 UI 线程需要下一帧应用布局：等待实际布局和路由确认，避免依赖机器运行速度。
- 采集了 8 秒 Perfetto 交互样本，记录在 `debug/verify/dashboard/interaction.pb`；该样本应用主线程最长已记录帧切片为 9.18 ms，不作为全局性能保证。
- 截图、测试、构建与运行日志在 `debug/verify/dashboard/`（调试目录，不进入业务数据或备份）。
