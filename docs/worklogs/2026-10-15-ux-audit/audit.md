# UX/UI 审查与交付记录

## 设计结论

本轮选择重构公共表单交互，而非只移动一个保存按钮，也不覆盖工作区已有的看板、账本、资产和统计改动。目标是单手可达、操作一致、错误可恢复，以及克制但明确的动效反馈。

采用 ui-ux-pro-max 的触控、可访问性、渐进披露与减少动态效果原则，并按 Expo SDK 57 官方文档实施。没有新增依赖、数据库迁移或持久化协议变更。

## 已落地

| 问题 | 实施方案 |
| --- | --- |
| 交易、账户编辑保存距离拇指远 | 统一固定底部主操作，编辑显示“保存修改” |
| 键盘出现后需要先收键盘再保存 | 单次点击提交；操作栏以真实布局避让键盘，不使用超出父边界的视觉位移 |
| 表单较长时保存按钮不可见 | 周期规则同样采用固定底栏；导入向导步骤按钮与滚动内容分离 |
| 保存失败后缺少反馈、容易重复提交 | 等待持久化完成再关闭；按钮显示保存中；同步锁防止连续点击；失败保留输入并提示 |
| 返回时无意丢失编辑 | 交易、账户、分类和项目提供未保存修改确认；优先关闭内部键盘/选择器 |
| 分类和项目编辑器重复且拥挤 | 抽取 IdentityEditor：底部面板、实时预览、字段标签、可滚动内容和键盘避让 |
| 图标一次展示过多 | 默认 12 个，当前选中图标始终保留；更多图标按需展开 |
| 控件过小、选中态依赖颜色 | 管理操作、图标和关闭按钮扩到 48dp，主操作最小 54dp；色块增加勾选标识及语义状态 |
| 强调色上的白字难读 | 统一填充色前景，覆盖四主题及支出/收入/转账选中态 |
| 缺少交互反馈 | 主按钮 120ms 按压回弹、记账入口缩放反馈、编辑面板 220ms 淡入上移；保留系统减少动态效果支持 |

## 路由审查矩阵

所有视觉证据均来自 Pixel_9 安卓模拟器 emulator-5554，不使用网页截图冒充原生界面。

| 页面/流程 | 审查结果与改动范围 |
| --- | --- |
| 看板 | 检查信息层级、空数据与底部记账入口；保留已有图表设计，补入口按压反馈及重复打开保护 |
| 流水账本 | 检查分组、行点击、滚动和底部导航；验证新编辑器保存后返回并更新交易 |
| 我的 | 设置入口增加按钮语义与按压反馈 |
| 新增交易 / 快速记账共用表单 | 固定保存栏、错误反馈、键盘单次提交；未改原生金额键盘实现 |
| 编辑交易 | 底部保存、退出保护、会话重置、并发提交保护、实际视口输入避让 |
| 交易搜索 | 检查搜索初始状态、输入键盘和结果面板；保留已有交互 |
| 筛选交易列表 | 检查金额/日期等筛选入口和现有列表结构；未重写筛选模型 |
| 账户列表 / 新增 / 编辑 | 统一保存路径，扩大输入、类型和图标触控范围，保护退出修改 |
| 资产历史 | 检查现有时间范围和图表布局；保留已有功能，避免扩大账务改动 |
| 统计分析 | 检查分类和趋势布局；复用既有图表及回归用例，不把前序改动记作本轮成果 |
| 分类管理 | 共享底部编辑器、扩大列表操作、图标渐进披露、颜色勾选 |
| 项目管理 | 共享编辑器；新增操作下移；空状态图标与明确主操作 |
| 周期交易 / 规则编辑 | 检查空状态、长表单和备注键盘；固定保存栏并进行输入避让 |
| 预算 | 检查周期/空状态和编辑面板；接入统一保存按钮及等待状态 |
| 导入 | 使用临时 CSV 走到选格式、列映射、数据映射、最终预览；底部前后步骤始终可见；没有执行导入写入 |
| 备份 | 检查备份入口、自动备份和恢复提示；未执行恢复或清库 |
| 汇率 | 检查缓存/更新入口和现有状态文案；未强制刷新外部服务 |
| 外观 | 浅色、深色、蒂芙尼蓝、薄荷绿均采样；验证后恢复深色偏好 |

## 模拟器验证

- 默认环境：1080 × 2424，420dpi；小屏环境：1080 × 1920，480dpi，即 360 × 640dp。
- 小屏与字体缩放 1.3 组合下采样交易表单和项目编辑器，键盘打开时输入内容、保存按钮仍可见。
- 以临时交易 UX_AUDIT_1015 验证新增和编辑：键盘打开时单击保存，账本正确显示修改；随后删除仅该测试交易，账本恢复 7994 笔与原收支合计。
- 其他既有交易的测试备注均放弃，没有保存到原记录。分类、项目和周期规则草稿均未保存。
- 模拟器原动画设置为 0；临时调整为 1 采集录屏，通过 finally 恢复。屏幕尺寸、密度和字体缩放亦已恢复。
- 保存失败、重复提交、未保存退出、会话重置通过组件回归覆盖；未在设备数据库中制造故障。

## 回归与构建

推荐复核命令：

```powershell
npm run typecheck
npm test -- --runInBand
cd android
.\gradlew.bat :app:assembleRelease -PreactNativeArchitectures=x86_64 --console=plain
```

- 最新全量回归日志：69 个测试套件、580 个用例通过。
- 本轮新增 15 个用例：保存交互 5 个、公共按钮 3 个、输入避让 3 个、主题对比度 4 个。
- 曾出现一次 TabPager 的既有时间相关用例失败；单独复跑 20 个用例通过，后续全量复跑通过，保留该波动记录。
- 类型检查无诊断；Android x86_64 release 构建成功，已用于模拟器采样。
- 模拟器构建不覆盖 build/release 下已有通用 APK；不是面向真机发布的新版本。

## 范围与限制

此次为所有现有路由的代码和视觉审查，不代表穷举所有数据、异常和设备组合。没有验证 iOS、平板、TalkBack 完整朗读流程，也没有宣称整个应用达到完整 WCAG 合规或真机帧率目标。模拟器的软件 GPU 录屏只用于交互与布局检查，不作为性能基准。导入落库、备份恢复、周期自动执行等高风险业务路径沿用已有自动化测试，没有对模拟器原账本进行破坏性演练。
