# 审查发现

## 环境与资料

- Expo 57.0.9、React Native 0.86.2、Reanimated 4.5.1。
- 已读取 SDK 57 官方文档：https://docs.expo.dev/versions/v57.0.0/ 。
- 使用 ui-ux-pro-max、brainstorming、expo-overview 与 planning-with-files 的审查和记录流程。
- 现有主要路由包括首页、账本、我的、交易新增/编辑/搜索、资产/账户、统计、分类、预算、周期交易、项目、导入、备份、汇率及外观。

## 已确认

- 交易编辑只有右上角保存，新建才有底部保存；账户编辑同样仅顶部保存。
- 账户新增、周期规则保存藏在长表单末尾；模拟器账户数量多时需多次滚动。
- 交易与账户保存会先关闭软键盘并返回，要求再次点击；保存异常还会被静默吞掉。
- 分类与项目存在几乎相同的居中编辑器、38dp 图标与 28dp 色块，无滚动与键盘避让。
- 所有主题强调色上的白字对比度不足，统一深色前景可覆盖现有强调色。
- 已采集主要路由的初始截图，存放于 debug/verify/ux-audit/before-*.png。
- 模拟器已有示例账本数据，初始 7994 笔；不清除其数据。
- 模拟器初始 GPU 渲染异常，切换 swiftshader 后可正常截图。Debug Metro 最初仅绑定 IPv6 localhost，已调整监听以连接模拟器。

## 实施与复核发现

- 已将交易、账户、周期规则主操作固定到底部，并增加异步状态与失败反馈。
- 键盘避让不能只使用视觉位移：按钮移动后若仍处于父容器边界之外，可能无法触控。改为实际布局占位，缩短内容视口。
- 不应以固定键盘高度补偿输入位置；提示文字、大字体会改变底栏高度。改为测量实际滚动视口，保留输入框下方间距。
- 分类与项目的图标默认展示 12 个，保留当前选中项，并提供展开更多，避免一次展示全部图标占满屏幕。
- 按钮、图标、颜色与管理列表操作扩大触控范围；主按钮与色块选择不再只靠颜色表达状态。
- 四种主题的填充按钮及交易类型选中态，前景对比度回归用例均达到 4.5:1。
- 默认模拟器动画缩放为 0；另以 1 倍动画录制面板进入、展开和返回，之后恢复原值。
- 全量测试曾出现一次既有 TabPager 时间相关用例失败；单独复跑及之后完整复跑通过，未修改该导航逻辑。
